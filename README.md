I build backend services with Django and Django REST Framework: APIs, the PostgreSQL
behind them, and the deployment around them. Outside work I write small self-hosted
tools, mostly Telegram bots that bring GitHub and Sentry events into chats or turn music
links into tagged audio files, plus a Yandex Music client for Linux written in Rust.

- 🔭 Currently polishing [github-webhook](https://github.com/mehroj-r/github-webhook) and [sentry-webhook](https://github.com/mehroj-r/sentry-webhook), my Telegram bots for GitHub and Sentry events
- 🦀 Writing Rust on the side: [yamarchy](https://github.com/mehroj-r/yamarchy), a Yandex Music client for Linux
- 💬 Ask me about Django, DRF, PostgreSQL or Telegram bots

### 📌 Selected projects

| Project | What it is | Stack |
| --- | --- | --- |
| **[github-webhook](https://github.com/mehroj-r/github-webhook)** | Telegram bot that forwards GitHub events to chats; re-run, approve and merge from Telegram | FastAPI, aiogram, PostgreSQL |
| **[sentry-webhook](https://github.com/mehroj-r/sentry-webhook)** | Sentry alerts in Telegram with routing, noise control, digests and issue actions | aiogram, aiohttp, SQLAlchemy |
| **[music-bot](https://github.com/mehroj-r/music-bot)** | Turns YouTube, Yandex Music and SoundCloud links into tagged M4A/MP3 files | aiogram, yt-dlp, SQLAlchemy |
| **[yamarchy](https://github.com/mehroj-r/yamarchy)** | Yandex Music client for Linux: playback daemon with MPRIS2, a CLI and an Omarchy panel | Rust, Tokio, zbus |
| **[url-shortener](https://github.com/mehroj-r/url-shortener)** | Invite-only link shortener with collections, expiring codes and click analytics | DRF, React, PostgreSQL |
| **[django_boilerplate](https://github.com/mehroj-r/django_boilerplate)** | Production-ready Django REST API templates, one branch per setup | Django, Docker |
